FTForge VPM

VRChat ネイティブ Face Tracking（Unified Expressions）用データを適用するパッケージ

VCC に追加

ボタンが使えない場合は、VCC / ALCOM の Settings → Packages → Add Repository に次の URL を入力してください。

https://fkaoi.github.io/ftforge-vpm/vpm.json

FTForge（com.ftforge.core）— FTForge のデータが入ったアバターを使う人向け。ビルド時にブレンドシェイプと Face Tracking 設定を適用します。
FTForge Authoring（com.ftforge.authoring）— データを作る人向けのツールです。使うだけなら不要です。
